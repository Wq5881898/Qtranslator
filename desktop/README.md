# Qtranslator Windows projects

- Qtranslator.Core: translation contracts, isolated data store and AI protocol client.
- Qtranslator.Desktop: WPF interface, screenshot OCR, translation and AI conversation. The application executable is Qtranslator.exe.
- Qtranslator.BridgeHost: the independent Chrome Native Messaging host.
- Qtranslator.TechnicalValidation: executable regression and protocol checks.

Build desktop/Qtranslator.slnx with .NET 10. See ../docs/QTRANSLATOR_AI_ZH.md for usage and product isolation. Do not replace an existing Translator installation or its extension.
