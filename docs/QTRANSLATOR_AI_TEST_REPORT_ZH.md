## 验证边界

本次本机交付为便携 ZIP；安装器身份及路径已静态验证，尚未编译或执行安装/卸载。

本次使用模拟 HTTP 服务验证协议，没有真实 API Key，没有调用示例中的收费模型。第三方服务 URL、模型权限、额度和自定义鉴权约定需要用户配置后实测。截图 OCR 使用内存生成的中英文测试图；没有完成真实其他应用窗口中的 Ctrl+Shift+D 截图手动验收。界面测试使用 WPF 离屏渲染，不替代安装后用户操作验收。

对话为内存会话，关闭应用不恢复。当前使用可选择复制的纯文本响应，不提供 Markdown 富文本、文件上传或工具调用。上下文 Token 检查采用保守估算。

现有依赖安装时报告 15 项审计问题；锁文件只更新了新产品的名称和版本，没有升级依赖。

## 建议用户验收

1. 保持旧程序运行，同时启动 Qtranslator.exe；确认两个标签页均可使用，两个产品的快捷键和收藏独立。
2. 配置一个有效 Key，手动发送中文问题，再发送追问；核对回复和多轮上下文。
3. 在其他应用按 Ctrl+Shift+D，框选中英文文字；确认只填入草稿，不自动发送。修改后发送。
4. 分别验证你实际使用的 Completions、Responses、Anthropic 服务；如不支持 SSE，关闭流式显示。
5. 验证停止、无效 Key、不可用 URL、输出上限、重试和新建对话。
