# 第二阶段收尾批次测试说明

## 本批目标

1. 截图快捷键可以配置，默认仍为 `Ctrl+Shift+X`。
2. 保存快捷键时立即检测系统热键冲突。
3. 新快捷键冲突时不覆盖设置，自动恢复此前可用的快捷键。
4. 截图识别成功后自动翻译，中文直接显示在下方结果框。
5. `Translate Chinese` 仅用于手动修改上方英文后的重新翻译。

## 快捷键测试

1. 启动桌面程序，确认状态区显示当前快捷键已就绪。
2. 点击 `Shortcut settings`。
3. 选择修饰键组合和一个 A–Z 字母，点击 `Save`。
4. 确认设置窗口关闭、状态区显示保存成功，界面顶部显示新的快捷键。
5. 在网页、PDF 或 Word 中按新快捷键并框选英文，确认截图、OCR 和翻译自动完成。
6. 退出并重新启动程序，确认快捷键设置被保留。
7. 选择一个已被其他程序占用的快捷键，确认界面提示冲突，原快捷键仍可继续使用。

## 自动与手动翻译测试

1. 使用快捷键框选清晰英文。
2. 确认英文出现在上方可编辑框，中文自动出现在下方结果框，不需要再点击翻译按钮。
3. 修改上方英文。
4. 点击 `Translate Chinese`，确认下方中文更新。
5. OCR、Chrome 扩展或本地桥接异常时，确认错误显示在当前窗口状态区，按钮能够恢复使用。

## 所有格和缩写符号回归

1. 截取包含 `week’s`、`Russia’s`、`America’s` 的英文。
2. 确认弯引号统一显示为标准英文撇号，例如 `week's`。
3. 确认不会再显示成 `week s`、`Russia s` 或 `America s`。
4. 修改为包含 `it's`、`don't` 的句子后手动翻译，确认撇号原样保留。
