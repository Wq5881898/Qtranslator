# Translator v1.1.2 最终回归测试报告

日期：2026-08-21

## 修复目标

- OCR 后第一次自动翻译即返回完整词典释义和音标，不依赖再次点击。
- `during` 不再因错误词根推导而查询 `dur`。
- `proud`、`during` 使用一致、易读的学习词典音标格式。

## 结论

v1.1.2 修复了用户报告的“自动翻译与连续第二次手动翻译结果不一致”问题。首次词典请求发生一次短暂故障时会自行恢复；若词典持续不可用，基础 Chrome 本地翻译仍可继续工作，不阻塞用户操作。

Chrome 对“已解压扩展”会缓存当前运行代码。覆盖安装后必须在 `chrome://extensions` 点击 Translator 的“重新加载”，或完全重启 Chrome，才能使用安装目录中的 v1.1.2；安装器不会强制关闭浏览器，以免丢失用户正在使用的页面。
