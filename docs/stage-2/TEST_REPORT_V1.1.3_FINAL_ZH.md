# Translator v1.1.3 最终回归测试报告

日期：2026-08-21

## 修复目标

- 保留 v1.1.2 的首次翻译一致性、原词优先及瞬时重试修复。

- `crouch` 显示 `/kraʊtʃ/`，`judge` 显示 `/dʒʌdʒ/`。

## 说明

连音弧是合法 IPA 组合符，并非读音数据本身错误；本版本为了在 Windows 中稳定显示，采用牛津、朗文等学习词典常见的无连音弧形式。升级后必须在 `chrome://extensions` 重新加载 Translator，或完全重启 Chrome，使浏览器使用 v1.1.3 代码。
