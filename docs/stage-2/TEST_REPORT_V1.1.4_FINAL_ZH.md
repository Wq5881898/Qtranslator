# Translator v1.1.4 最终回归测试报告

日期：2026-08-24

## 用户问题

- 同一单词手动点击一次与点击两次可能出现不同解释。
- Windows 桌面程序在 Bridge 波动时可能自动结束进程。

## 根因与修复

词典异常此前被静默转换为“没有词典结果”，导致第一次显示基础翻译，后续请求成功后显示完整词典翻译。v1.1.4 在一次操作内进行三次有限重试，缓存成功词条，并在持续失败时明确报错。

桌面端 Bridge 健康检查此前位于 `try/catch` 之外，异常可从 WPF 的异步按钮事件逸出并终止进程。v1.1.4 将完整翻译过程纳入异常边界，并增加全局诊断保护。

## 开发验证程序异常复核

截图中的 `Translator.TechnicalValidation.exe` 弹窗已通过 Windows 事件日志定位：Windows 应用控制策略阻止加载开发暂存目录中的 `Translator.Desktop.dll`，运行库随后抛出 `FileLoadException (0x800711C7)`。它属于开发验证工具及本机安全策略组合问题，不是正式桌面程序的翻译异常。

正式安装器不包含 `Translator.TechnicalValidation.exe`。源码回归改用已构建项目的 `dotnet run --no-build` 执行，11 项技术检查全部通过，且不再启动被系统策略拦截的自包含验证副本。
