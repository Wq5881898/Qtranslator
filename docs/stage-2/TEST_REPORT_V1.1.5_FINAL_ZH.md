# Translator v1.1.5 回归测试报告

日期：2026-08-25

## 用户问题

- Windows 端频繁停留在“首次语言包准备”提示，即使 Chrome 已打开且数分钟前仍可翻译。
- 日志同时出现免费词典超时和 `The local translation page did not start`。

## 根因

Chrome 可能保留 offscreen 文档对象，但在扩展 Worker 生命周期变化后丢失其 runtime Port。旧逻辑只检查文档是否存在，因此不会重建孤立页面。Bridge 健康检查仍成功，导致桌面端进入翻译等待后失败。

单词翻译又把在线免费词典作为成功前置条件；词典服务波动会阻断本来仍可工作的 Chrome 本地基础翻译。桌面等待文案把多个阶段统一描述成语言包准备，掩盖了真实故障点。

## 修复

- 文档存在但没有活动 Port 时关闭并重建 offscreen 翻译页面；
- 页面启动、断连或请求超时后重建并自动重发一次幂等请求；
- 免费词典连续失败时降级为基础翻译，不阻断中文结果；
- 降级结果明确标记并提示可能缺少音标和扩展释义；
- 等待提示改为准确描述完整处理链路。

## 验证范围

- 孤立 offscreen 文档判定；
- 词典三次失败后的基础翻译降级；
- 原有音标规范化、会话重建、连续手动翻译一致性；
- TypeScript 类型检查、扩展测试、Release 构建、Windows 技术验证；
- 安装器内容、版本和正式桌面程序启动持续运行。
