# Translator v1.1.7 回归测试报告

## 修复范围

本版本针对 v1.1.6 单词查询出现的数秒等待、词典失败后长时间缺少音标及多义项、浏览器与 Windows 结果未显示词性等问题进行修复。

## 实现变更

1. 删除单词词典失败后的五分钟冷却，不再因一次失败持续降级。
2. 主词典网络失败时只进行一次 50ms 快速重试。
3. 主词典超过约 250ms 或失败时，启动 Datamuse 备用查询；正常快速响应时不产生备用请求。
4. 将单词、最多三条英文释义合并为一次 Chrome 本地翻译调用，替代逐条串行调用。
5. 结果模型增加词性数组，并贯通浏览器侧边栏、Native Messaging 和 Windows 界面。
6. 两个词典的成功查询均由 Provider 会话缓存，重复查询不再次访问网络。

## 自动化验证

- TypeScript 类型检查：通过。
- Vitest：12 个测试文件、56 项测试全部通过。
- Windows Release 编译：4 个项目通过，0 警告、0 错误。
- 新增覆盖：备用词典 IPA、词性、多个定义；一次模型调用；词典快速失败与恢复。

## 人工测试重点

安装后请连续查询 `baby`、`proud`、`crouch`、`consultation` 和 `granted`，确认：

- 首次结果显示音标、词性和多个中文解释；
- 同一单词连续查询结果一致，无需点击两次；
- 浏览器插件和 Windows 端显示字段一致；
- 主词典不可用时不会长时间停留在“检查词典”状态。

## 已知边界

Chrome 本地语言包第一次下载仍可能由 Chrome 自身产生一次性等待。两个公共词典同时不可达时，程序会在约 1.2 秒内降级为基础中文翻译，不会无限等待。
